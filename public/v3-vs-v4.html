nexus v3 vs v4

What changed, side by side. v3 is 3.2.1, the release on PyPI. v4 is the 4.0.0a1 preview on the v4-preview branch. new exists only in v4, changed works differently, same works the same.

v3 and v4 on One Machine

  • nexus stays v3 and nexus4 runs the preview; installing one doesn't touch the other.
  • A project uses the version that last ran init or sync in it — nexus4 doctor shows it ("Project synced by").
  • Copies in ~/.claude/commands/ run instead of the project's. Measured on 2026-11-24: with a v3 commit.md there, /commit in a v4 project ran the v3 one. While you work on v4, move those copies aside (for example to ~/.claude/commands-v3/) and back when you return to v3. nexus4 doctor lists them ("Global command copies"), and nexus4 init warns about them.
